# Inscriptarc to Ianseo

**Version 1.0.0**

Ce module complémentaire pour **Ianseo** permet l'intégration facilitée dans le logiciel d'une gestion des inscriptions via **Inscriptarc**. Il gère également la non prise en compte dans le classement les départs additionnels des archers.

> Il est recommandé de remplacer par le fichier fournit, le fichier `ListLoad.php` situé dans `htdocs > Partecipants` pour profiter du module à 100% (prise en compte du départ de chaque inscription).

1. Ajoutez le dossier téléchargé `InscriptarcImport` dans le dossier `htdocs > Modules > Custom`
2. Utilisez le module dans Ianseo depuis l'onglet **Modules**
